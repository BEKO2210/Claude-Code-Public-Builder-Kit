Kurzüberblick

Das Builder Kit verarbeitet so wenig personenbezogene Daten wie technisch möglich:

  • Es gibt keine Cookies, kein Tracking, keine Analytics-Tools, keine Werbe-Pixel und keine Social-Media-Plugins.
  • Die von Ihnen eingegebene Projektidee wird im Arbeitsspeicher verarbeitet, um daraus die 12 Markdown-Dateien zu erzeugen, und danach verworfen.
  • Es gibt kein Nutzerkonto und keine Anmeldung.
  • Im Browser wird ausschließlich die gewählte Sprache in localStorage gespeichert (kein Tracking, niemals an einen Server übertragen).
  • Die zugrundeliegenden Hosting-Dienste (Vercel, GitHub Pages) verarbeiten zur Bereitstellung der Seite technisch notwendige Daten wie IP-Adressen — Details unten.

2. Welche Daten werden erhoben?

2.1 Eingabe der Projektidee

Wenn Sie eine Projektidee eingeben (im Wizard oder im direkten Eingabefeld) und auf „Kit erzeugen" klicken, wird der Text per HTTPS an den Server des Tools auf vercel.app übertragen, dort im Arbeitsspeicher verarbeitet, und das Ergebnis sofort als JSON oder ZIP zurückgesendet. Die eingegebene Idee wird nicht in einer Datenbank gespeichert, nicht protokolliert und nicht an Dritte weitergegeben.

Bitte geben Sie keine personenbezogenen Daten oder vertraulichen Informationen in das Eingabefeld ein. Eine Idee wie „Eine App für Eltern kleiner Kinder" enthält keine personenbezogenen Daten und ist unproblematisch.

2.2 Server-Logs

Der Hosting-Anbieter Vercel kann beim Aufruf der Seite und der API-Endpunkte automatisch technische Daten in Server-Logs erfassen, insbesondere:

  • IP-Adresse (in der Regel anonymisiert)
  • Datum und Uhrzeit der Anfrage
  • aufgerufene URL
  • HTTP-Statuscode
  • User-Agent (Browser-Kennung)

Diese Daten werden ausschließlich zur Bereitstellung des Dienstes, zur Aufrechterhaltung der Sicherheit (z.B. Erkennung von Missbrauch) und zur Fehleranalyse verarbeitet. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einem stabilen, sicheren Dienst). Die Speicherdauer richtet sich nach den Vorgaben von Vercel.

Datenschutzerklärung von Vercel: vercel.com/legal/privacy-policy

2.3 Rate Limiting

Um Missbrauch zu verhindern, hält das Tool im Arbeitsspeicher der jeweiligen Server-Instanz einen Zähler pro IP-Adresse vor (max. 30 Anfragen pro Minute). Dieser Zähler wird nach Ablauf des Zeitfensters verworfen. Es findet keine dauerhafte Speicherung statt.

2.4 Landingpage (GitHub Pages)

Die Startseite unter beko2210.github.io/Claude-Code-Public-Builder-Kit wird über GitHub Pages bereitgestellt (Anbieter: GitHub Inc., USA). GitHub kann beim Aufruf technisch notwendige Daten wie IP-Adresse und Browser-Kennung verarbeiten.

Datenschutzerklärung von GitHub: docs.github.com/en/site-policy/privacy-policies

2.5 Browser-Speicher (localStorage)

Im lokalen Browser-Speicher (localStorage) wird ausschließlich die von Ihnen gewählte Sprache (en oder de) hinterlegt, damit Sie nach erneutem Aufruf der Seite weiterhin in Ihrer bevorzugten Sprache lesen können. Diese Information verlässt Ihren Browser nicht, wird nicht an einen Server übertragen und kann von Ihnen jederzeit über die Browser-Einstellungen gelöscht werden.

Es werden keine Cookies gesetzt.
