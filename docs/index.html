Turn one sentence into a planning foundation.

The Claude Code Public Builder Kit takes a one-line project idea — "a SaaS dashboard for small business accountants" — and produces 12 substantive Markdown files: vision, roadmap, acceptance criteria, architecture, and ready-to-paste Claude Code prompts. Locally, in a few seconds, with no cloud account and no LLM dependency.

What you get

For every idea you enter, the kit produces the same twelve files. Substantial content; no orphan TODO stubs (the test suite enforces it).

README.md

Project entry point with quick start and structure.

CLAUDE.md

Operating rules for any Claude Code session in your repo.

MASTERPLAN.md

Vision, scope, success metrics — the single source of truth.

ROADMAP.md

Five phases from foundation to scale, each with an exit gate.

RUN_LOG.md

Append-only session journal, seeded with Run #001.

ACCEPTANCE_CRITERIA.md

Phase-tied checklists of what "done" actually means.

ARCHITECTURE.md

Recommended starting architecture and open questions.

PROMPTS/initial-prompt.md

A drop-in first prompt to start your Phase 0 session.

PROMPTS/run-plan-20-sessions.md

A 20-session execution plan from empty repo to product.

DOCS/product-brief.md

Audience, jobs-to-be-done, top user stories.

DOCS/market-positioning.md

Positioning statement and competitive frame.

DOCS/technical-decisions.md

Stack candidates and an ADR template for the decisions you make.

Quick start

Anything with Node 18+ runs this. No accounts. No build step.

git clone https://github.com/BEKO2210/Claude-Code-Public-Builder-Kit
cd Claude-Code-Public-Builder-Kit
npm install
npm start
# open http://localhost:5173

From the UI you can generate a kit, copy any of the 12 files, or download the whole bundle as a ZIP. Generated kits land in output/<slug>/ on disk.

Use the API directly

curl -s -X POST http://localhost:5173/api/generate.zip \
  -H 'Content-Type: application/json' \
  -d '{"idea":"A SaaS dashboard for small business accountants"}' \
  -o kit.zip

Why this exists

The hardest part of starting a project isn't writing code — it's answering "what am I actually building?" without spending two weeks on a wiki nobody reads.

This kit collapses that gap. Twelve files, opinionated where it helps, explicit about its assumptions where it can't know. You sharpen them in MASTERPLAN.md, drop the initial prompt into Claude Code, and start building from a clear starting line.

Nothing is hidden. The generator is a few hundred lines of plain Node.js, deterministic, with a 24-test suite and CI that fails if a worked example drifts. There is no telemetry, no LLM call, no cloud dependency.
