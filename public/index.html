Use your kit in 3 steps

Built for Claude Code — in your browser via GitHub, or in your terminal. No regular chat — Claude Code can actually read and edit the files in your kit.

  1. 1

    Download your kit

    A ZIP file with 12 markdown documents — your project plan, ready to share.

  2. 2

    Upload to GitHub (free)

    Claude Code in the browser works with a GitHub repo. Takes about 3 minutes the first time. Already have GitHub? Skip step 2a.

    Show step-by-step (for first-time GitHub users)
    1. 2a. Go to github.com/signup and create a free account (just email + password).
    2. 2b. Click the + top-right → New repository. Pick any name (e.g. my-kit), choose Public, leave the rest as default, click Create repository.
    3. 2c. On the new empty repo page, click the link uploading an existing file.
    4. 2d. Open the ZIP you downloaded in step 1. Drag all the files from inside the ZIP onto the GitHub upload page.
    5. 2e. Scroll down, click the green Commit changes button. Your kit is online.
    Open GitHub: New repository ↗
  3. 3

    Open Claude Code with your repo

    Open Claude Code in your browser, connect the GitHub repository you just created — Claude Code will load all 12 files automatically. Then paste this prompt:
